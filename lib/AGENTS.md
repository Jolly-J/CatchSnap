# lib 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`lib` 是本应用（极简、轻量、多线程多平台高清视频下载器）的核心源码目录。采用分层原子化架构设计，UI 全面契合爱彼迎（Airbnb）设计哲学，业务逻辑遵循“纯本地免服解析 + 按需权限授权 + 多线程分片下载 + 流体云状态通知”。

## 子模块职能划分

| 目录/文件 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `main.dart` | 应用入口与生命周期托管 | 托管 App 初始化、全局主题挂载、前台回切时的单次剪贴板感知。**严禁在启动时强弹阻断式权限申请**。 |
| `app_theme.dart` | 爱彼迎设计规范资产中心 | 定义爱彼迎品牌色（`#FF385C`）、极简灰度（`#222222`, `#717171`, `#F7F7F7`）、标准圆角（16~24dp）、柔和弥散阴影、字阶规范。 |
| `core/` | 基础底座与通用引擎 | 包含多线程 Range 分片下载引擎、安全本地加密存储、全局底层常量。与具体平台业务解耦。 |
| `models/` | 数据实体层 (Entities) | 统一定义媒体实体（`MediaItem`）、下载任务与分片状态（`DownloadTask`）、平台枚举（`PlatformType`）。无外部副作用。 |
| `parsers/` | 平台本地解析引擎 | 纯客户端免签与 Cookie 增强解析。支持抖音（Douyin）与小红书（Xiaohongshu）高清直链无水印提取。 |
| `services/` | 业务能力与系统协调服务 | 包含剪贴板按需检测、多平台 Cookie 会话、下载任务调度、按需权限申请、流体云进度同步服务。 |
| `utils/` | 纯函数工具库 | 涵盖正则提取、文件尺寸与速率格式化、时间工具，只提供无状态纯计算。 |
| `widgets/` | 爱彼迎风格原子组件库 | 封装爱彼迎胶囊搜索框、圆角弹性卡片、流体云微动效胶囊、底部吸底浮窗。 |
| `screens/` | 表现层与交互页面 | 包含首页大胶囊交互、解析详情页多清晰度选择、内置 Web 登录提取 Cookie、下载历史与设置面板。 |

## 协作守则
1. **代码注释规范**：所有文件必须附带抬头元数据注释，函数与关键分支必须附带详尽的代码块注释。
2. **纯本地与隐私第一**：绝不设置任何后台静默网络外联，用户 Cookie 与历史记录一律在设备内部沙盒加密管理。
3. **性能保证**：多线程下载引擎必须严格控制分片数量与内存 Buffer，杜绝 OOM。
