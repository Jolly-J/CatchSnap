# widgets 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`widgets` 模块包含应用高度复用的原子 UI 组件。严格遵循**爱彼迎 (Airbnb) 设计语言规范**：极简、呼吸感大圆角、微渐变高质感珊瑚红（`#FF385C`）、微阴影与温润触控交互反馈。

## 核心文件清单与职责

| 文件名 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `airbnb_button.dart` | 爱彼迎质感按钮组 | 提供主操作胶囊按钮（Rausch 珊瑚红渐变）、次级边框药丸按钮、图标轻量按钮。内置弹性缩放微动效。 |
| `airbnb_card.dart` | 爱彼迎规范卡片容器 | 带有 16~24dp 大圆角、超细微边框（`#EBEBEB`）与多层漫反射柔和阴影，保证信息层级清晰明快。 |
| `fluid_cloud_capsule.dart` | 流体云 (Fluid Cloud) 灵动药丸胶囊 | 位于界面顶部的动画药丸胶囊，在空闲时隐形，下载时自然膨胀为动态进度条，展示实时下载速度与完成态。 |
| `clipboard_prompt_sheet.dart` | 剪贴板识别底部模态卡片 | 当用户返回 App 探测到新短链时，以爱彼迎经典底部抽屉形式优雅升起，支持一键填入并直接发起解析。 |
| `snap_toast.dart` | 灵动顶部胶囊 Toast 提示 | 替代原生生硬底部黑色 SnackBar，以顶部灵动岛胶囊微动效滑入滑出，呈现现代化呼吸感提示。 |
