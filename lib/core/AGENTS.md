# core 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`core` 目录存放应用最底层的引擎与基础能力，对上层业务（UI、具体解析器）完全透明并提供高内聚、低耦合的接口。

## 核心文件清单与职责

| 文件名 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `constants.dart` | 全局基础常量与键名 | 统一定义 SharedPreferences 存储键名、平台枚举字符串、默认请求超时与 User-Agent。严禁业务硬编码。 |
| `download_engine.dart` | 高性能多线程分片下载引擎 | 负责向远程服务器发起 HTTP Range 请求切片、并发连接调度、多线程断点分片合并、实时瞬时速度计算与中断控制。 |
| `security_storage.dart` | 本地安全存储门面 | 封装对 Cookie、配置项与应用缓存的读写，确保用户敏感会话仅保留在本地。 |

## 设计规范
1. **多线程安全性**：下载引擎采用原子切片写入（基于 RandomAccessFile），分片合并过程中自动校验字节长度与完整性。
2. **容错机制**：如果远程服务器不支持 HTTP `Accept-Ranges: bytes`，自动平滑降级为普通单线程流式传输，避免任务失败。
