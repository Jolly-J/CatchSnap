# utils 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`utils` 目录存放无副作用的纯函数工具类，负责字符串清洗、正则表达式提取、数据度量衡换算等。

## 核心文件清单与职责

| 文件名 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `link_extractor.dart` | 智能链接提取器 | 从用户粘入的复杂分享文案或混合文本中，使用精准正则提取抖音（`v.douyin.com`）与小红书（`xhslink.com`）有效 URL。 |
| `format_utils.dart` | 格式化工具包 | 包含字节尺寸（B/KB/MB/GB）、瞬时网速（KB/s、MB/s）、媒体时长与时间戳的人性化格式转换。 |
