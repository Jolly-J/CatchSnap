# models 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`models` 模块定义应用内部流转的全部核心数据结构（Entities）。设计原则是**纯数据表达、强类型契约、零副作用**。

## 核心文件清单与职责

| 文件名 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `platform_type.dart` | 平台类型枚举 | 定义支持的短视频与社交平台（抖音 Douyin、小红书 Xiaohongshu、预留微信视频号 WeChat）。提供图标与品牌色映射。 |
| `media_item.dart` | 统一媒体解析结果实体 | 整合图集、单一视频、Live 实况动图，标准化作者、标题、点赞量、多画质流链接及背景音乐。 |
| `download_task.dart` | 下载任务与分片状态实体 | 记录当前任务的下载状态（待下载、下载中、成功、异常）、总体进度、分片状态及瞬时速度。 |

## 设计规范
1. 属性不可变性（Immutability）：模型字段优先采用 `final` 修饰，状态变更通过 `copyWith` 实现。
2. 平台差异归一化：无论抖音还是小红书，解析完成后统一输出为 `MediaItem`，解耦 UI 渲染与平台差异。
