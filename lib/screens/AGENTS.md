# screens 模块架构规范与职能分工 (AGENTS.md)

## 目录概述
`screens` 目录组织应用全部完整的用户交互页面。遵循**爱彼迎 (Airbnb) 设计风格**：通透的留白、粗体大标题、极简大胶囊搜索栏、柔和圆角卡片、流体云浮窗与无侵入式交互。

## 核心页面清单与职责

| 文件名 | 职能定位 | 维护与设计原则 |
| :--- | :--- | :--- |
| `home_screen.dart` | 应用主页 | 爱彼迎大胶囊链接输入栏、快捷清空/粘贴、热门支持平台指示、顶部流体云灵动胶囊容器、进 App 剪贴板自动呼出。 |
| `video_detail_screen.dart` | 解析结果详情与下载页 | 展示媒体封面/播放直链预览、作者与发布信息、多清晰度（1080p/720p/原画）选择器、图集批量下载与单张选择、多线程实时进度条。 |
| `web_login_screen.dart` | 内置 WebView 登录获取 Cookie 页面 | 呼出平台官方移动端登录页面（抖音/小红书），在用户登录成功后自动通过 `CookieManager` 抓取并回传本地加密存储，赋能 1080p 高清无水印解析。 |
| `history_screen.dart` | 下载任务管理与媒体库中心 | 爱彼迎双 Tab 架构：进行中任务实时下载流（进度条、网速、取消）与已完成媒体库归档，支持直接进入详情、单条剔除与一键清空。 |
| `settings_screen.dart` | 偏好设置与系统配置 | 提供多线程并发数调节滑块（1~8线程）、流体云开关与延迟设置、各平台 Cookie 状态与一键重登入口、相册分类路径自定义。 |
