# 咔捕品牌元素

本目录统一管理咔捕的 Logo、品牌机器人、参考图片和生成提示词。后续新增品牌素材统一存放在这里。

## 目录

| 目录或文件 | 内容 |
| --- | --- |
| `Logo/` | 用户提供的原版 Logo，以及生成的放大镜侦察版主视觉 |
| `动作形象/` | 当前选用的 10 张独立动作图 |
| `参考原图/` | 用户提供的机器人表情贴纸合集，用于造型参考 |
| `提示词/` | 固定角色基底及各张图片的完整生成提示词 |
| `系统图标/` | 暖白底 Android 自适应、单色主题、传统图标及商店导出资源 |
| `历史版本/` | 未选用的旧稿及对应提示词 |
| `交付包/` | 已打包的主 Logo 和 10 张动作图，包含提示词与清单 |
| `交付清单.json` | 当前选用文件的相对路径、尺寸、透明通道信息及 SHA-256 |

## 维护约定

- 新增动作图时复用 `提示词/角色固定基底.txt`，保持同一角色，只调整动作、表情和少量道具。
- 当前选用图片使用「两位编号-动作名称.png」命名；完整提示词使用同名加 `-prompt.txt`。
- 更换当前版本前，将旧图片与旧提示词一起归档到 `历史版本/`，文件名加版本号。
- 更新素材后同步更新 `交付清单.json`；对外交付时同步更新 `交付包/`。
- 系统图标已接入 Android 资源；规格、平台差异及验证范围见 [系统图标说明](系统图标/README.md)。其他品牌素材按需要接入 Flutter 资源与页面引用。
